# NXPULSE web

[Abre la aplicación](https://yoshstars.github.io/nxpulse-web/)

Versión web compilada de NXPULSE: publicaciones, likes, comentarios, perfiles y guardados.

Demo local: cada navegador guarda sus propios datos. No hay usuarios conectados entre dispositivos.

Este repositorio contiene exclusivamente los archivos de publicación. El proyecto fuente se conserva en el repositorio privado sonora-audio.
